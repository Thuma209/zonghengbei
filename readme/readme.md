经济官员基本职责
“世界更多地被思想，而非金钱统治。”——约翰·梅纳德·凯恩斯，1936年
经济官员是每个代表团的经济事务负责人，席位名称一般为财政部长/财政大臣，负责管理本国的宏观经济与对外贸易，掌握国家财政并有权制定各种经济政策和战略，通过经济决策最大化本国利益。作为一名优秀的经济官员，您应该做到：
（一）基本掌握本次会场所适用的经济系统规则，并对其基本运行机制、操作方法和可能适用的相关经济学知识有基本了解；
（二）能够较好管理本国经济，首先维持其基本运转，完成本国预设基本任务，在此基础上扩大盈余，创造竞争力；
（三）设计本国基本的经济发展战略、目标和具体措施，并根据实际情况随时进行修订；
（四）与团队负责人共同制定国家贸易政策、经济政策、国内税率、关税税率等经济政策；
（五）和其他部长进行有效沟通和合作（与外交部长合作开展经济外交、贸易外交等；与政府新闻发言人合作发表本国财报；与军事负责人合作完成军事生产与训练计划、后勤补给计划等）











资源
“我们必须保证我们的工业每年能生产五千万吨生铁、六千万吨钢、五亿吨煤和六千万吨石油。只有这样，我们才能确保祖国在任何不测事件中的安全。”——约瑟夫·斯大林，1946年
资源对经济发展和战争至关重要。在本赛事中，资源共有九种：
九种资源一览
资源类型	资源名称	用途
矿石资源	生铁	精炼钢铁的原料
	煤炭	为火车和发电厂提供动力，是钢铁和合成燃油的燃料
	铝土矿	精炼铝的原料
精炼资源	钢	大多数军用机械的主要材料，如坦克、舰船
	铝	对制造特种车辆和飞机非常重要
	橡胶	对生产大部分车辆非常重要
	石油	正常使用车辆、飞机和舰艇所必需的燃料
	铬	用于专门的机械元件，或作为添加剂提高钢铁产量
	钨	用于生产机床和穿甲弹的重要原料
这九种资源当中，除钢、铝外，都可以从地块自然产出，其中石油和橡胶也可以建造相关的资源工厂来获得（需要解锁对应的科技）。大多数情况下，本赛事中的“资源”指的是每回合的产出。每个代表团都拥有一个亚空间仓库，可以随时任意存取任意数量的资源；此外还有电力，该资源不可交易。
各国每回合资源增长的速度由以下条件决定：贸易政策：贸易政策决定了占比多少的资源被卖出以换取buff；在贸易政策影响下固定出口的资源之外向其他国家卖出的资源，它决定了你可以通过出口换取多少工业能力；以及军事和民事生产所需的各种资源。最终，本回合盈余的资源会被存入仓库；亏损的资源会优先从仓库中扣除，若资源工厂的资源不足，则会按比例对使用该资源的产线进行惩罚；若军备生产的资源不足，则会退还所有资源并将该操作视为无效。
任何生产配方所需的多种资源中，以满足比例最低的那种资源为准，产出按该比例折算，其余资源按同比例消耗，未消耗部分留在仓库。例：炼钢需40铁、10煤、5电。现有铁40、煤6、电5，煤的满足率为60%（6÷10），则本回合产出 = 24×60% = 14.4钢，实际消耗铁24、煤6、电3。制造一个一级飞行联队需230ic，50飞机产能，30铝，20发动机产能，10橡胶，任意一种资源不够都会导致建造失败，返还所有资源。电力惩罚则不针对厂计算，按全国电力缺口比例给予国家debuff，影响全国工厂产能。具体阈值和梯度为：缺1/3以下每回合稳定度-5，军备产出-5%；缺1/3以上2/3以下每回合稳定度-10，军备产出-10%，民工产出-5%；缺2/3以上每回合稳定度-10，军备产出-15%，民工产出-10%。
工业能力
“我们必须成为民主国家的伟大兵工厂。”——富兰克林·D·罗斯福，1940年
在开始之前先让我们来介绍一下“工业能力”这个名词。工业能力是基于历史上国家的经济能力抽象简化而成，是进行一切经济活动的核心。用专业一点的术语来说，工业能力在本次赛事中充当商品等价物，起到类似于货币的作用。考虑到不同用途的工业能力之间转化并不方便，我们将工业能力分为三个部分：民用ic，军用ic，军舰用ic。
每回合工业能力的增长大致来源于工厂产出与贸易盈余两个部分。其中工厂产出与工厂数量有关，贸易盈余与该国家贸易情况有关。而每回合工业能力的消耗主要本回合建设有关。

民用IC盈余公式：
y_{civ}=\left(1-\alpha_1\right)\cdot\alpha_2\cdot F_{civ}-\alpha_3\cdot C+T
其中 F_{civ} 为民用工厂总产出，C 为本回合建设开支。\alpha_1为消费品系数（反映多少产能被消费品占掉），\alpha_2 为民用产出加成，\alpha_3 为建造成本系数，T 为贸易盈余。（所有来源的百分比修正（政策、国家精神、科技等）均为加算，不做乘算叠加。例如某项+10%与另一项+5%，合计为+15%）

军用IC与军舰IC盈余公式：
y_{mil}=\beta_1\cdot F_{mil}-\beta_2\cdot O-M
其中 \operatorname{F}_{mil} 为军用工厂/船坞总产出（以下简称军备产出），O 为订单开支，M 为维护费。\beta_1 为军工/船坞产出加成，\beta_2 为军备订单加成。军用IC和军舰IC用同一套公式结构，但ic各自独立算各自的。订单开支O是你当回合下的军备生产生产订单所花费的 IC数目。
军用和民用IC的盈余均可以保留至下个回合。

占领领土产出：
最终产出 = 原始产出 × 占领系数 × 航线安全系数
非核心领土占领系数50%。航线安全系数仅在需要海运时适用，陆路可达则为1。
设施建设
“工事，火炮，外援都毫无意义。除非普通的士兵都清楚，他，正在保卫国家。”
——卡尔·古斯塔夫·埃米尔·曼纳海姆，1939年
每个国家的经济官员都可以消耗一定的成本和时间，在本国领土上建设各种工业生产设施、军事生产设施、资源生产设施、军事设施、修复被损毁的设施或搬迁设施。所有建造一回合均可完成。
工业生产设施方面：
每个国家可建、民用工厂、军用工厂、海军船坞，在本次赛事中均称为“工业设施”。工业设施消耗的是民用工厂产能。
民用工厂：产量64民用ic，建造成本为800，电力消耗为8，每回合钨消耗为0.1
军用工厂：产量30军用ic，建造成本为800，电力消耗为10，每回合钨消耗为0.1
海军船坞：产量45船用ic，建造成本为2400，电力消耗为30，每回合钨消耗为0.1
（注：若钨数目不足，则会导致产能扣减，缺多少扣多少产出，扣减顺序如上）

军事生产设施方面：
每个国家可建设火炮铸造厂、发动机工厂、坦克装配厂、飞机装配厂，在本次赛事中均称为“军事生产设施”。军事生产设施消耗的是民用工厂产能。军事产能盈余不保留至下回合。本回合不足则会受到惩罚。
火炮铸造厂：产出7火炮产能，工业消耗能力为500，电力消耗为6
发动机工厂：产出7发动机产能，工业消耗能力为750，电力消耗为6
坦克装配厂：产量6坦克产能，工业消耗能力为1000，电力消耗为6
飞机装配厂：产量6飞机产能，工业消耗能力为1000，电力消耗为6
（以上产量均为每回合产出，回合内盈余资源会直接消失。本资源也不可贸易。）

资源生产设施方面：
每个国家可建设炼钢厂、炼铝厂、合成炼油厂、合成橡胶厂、火力发电厂，在本次赛事中均称为“资源生产设施”。资源生产设施消耗的是民用工厂产能。
炼钢厂：产出24点钢，工业消耗能力为480，电力消耗为5
炼铝厂：产出16点铝，工业消耗能力为480，电力消耗为15
合成炼油厂：产出2.5燃油，工业消耗能力为2500，电力消耗为20
合成橡胶厂：产出10橡胶，工业消耗能力为3000，电力消耗为30
火力发电厂：产出120点电力，工业消耗能力为800
（以上产量均为每回合产出，回合内盈余资源会被送进仓库）

军事设施方面：

每个国家可以在指定区块上修建陆地要塞/海岸要塞，和工业生产设施建设不冲突。军事设施对战斗结果具有修正效果（见军事文件）。
陆地要塞：工业能力消耗为4000（＋1000每级，最高5级）
海岸要塞：工业能力消耗为5000（＋1000每级，最高5级）

国际贸易
“当货物流动时，士兵就不必流动。”——美国国务卿科德尔·赫尔，1930年代
在大部分情况下，国家无法自行满足自己的产品需要，或者国内无法完全消化本国的产品供给，为了使这些稀缺/盈余产品的价值得到充分的实现，经济负责人可以和外交负责人合作，根据本国需求与其他国家进行贸易外交。

双边贸易

两国可通过外交协商签订双边贸易协定，约定资源种类、数量和价格，不经过集合竞价市场。协定一经签订每回合自动执行，修改或取消须另行通知推演组。航线安全系数仍适用。贸易外交可以通过签订贸易协定，国家之间可以通过工业能力来买卖资源、军备以及借贷。贸易协定规定的交易对每回合都生效，若要取消请说明。


我们推荐向资源丰富的中立国购买资源（要不然就只能资敌或者自己去抢了）。因此，为方便各位代表进行贸易，除与玩家进行贸易外，玩家可以向推演组控制的中立国购买所需资源或卖出多余资源换取ic。无论通过何种方式成交，实际到货量受后勤运输影响（参见“后勤运输”）。买方按原始成交数量全额付款，航线损耗由买方承担。


军队贸易一般可以用于陆军装备（与军事系统相同，最少为一个步兵军或装甲军），空军飞机（同样的，最低100架）和海军舰队。如果国情报告里没有相应的特性则不能交易。特别的，对于海军贸易，前提是舰船可以通过运输运送到该国，沿途没有任何海域被敌方舰队和地块控制。




指令模板如下：
本回合使用X点工业能力于XX国进口XXX资源。（贸易进口指令）
本回合出口XXX至XX国，其使用X点工业能力支付。（贸易出口指令）
（若贸易指令已于贸易协定中确定，请提及相应贸易协定）
本回合于XX国进口XXX，细则详见《XX协定》第X条。（贸易进口指令）
本回合出口XXX至XX国，细则详见《XX协定》第X条。（贸易出口指令）
本回合向X国提供价值X的贷款，利率X%，X回合到期/分期还款



军需官员基本职责
“必须尽一切可能，把全部经济力量都集中到战争需要上来。我们决不能允许任何无关紧要的消费品生产，来妨碍我们军工生产的步伐。” ——阿尔伯特·施佩尔，1942年
军需官员是每个代表团中负责军事物资保障与装备生产事务的核心成员，席位名称一般为军需总监/装备部长，负责管理本国的军事生产、资源调配、装备分配与后勤保障。作为一名优秀的军需官员，您应该做到：

（一）基本掌握本次会场所适用的军事生产与后勤运输系统规则，理解装备生产配方、资源消耗、运输机制及其对前线作战的影响；

（二）能够较好管理本国的军事生产体系，确保军队装备需求得到满足，完成本国预设的军备建设任务，在此基础上提升装备质量与数量，增强战斗力；

（三）设计本国的军备发展战略，包括装备生产优先级、军工设施布局、资源储备策略，并根据战场形势和外交变化随时调整；

（四）与团队负责人共同制定军事生产计划、装备分配方案、后勤补给策略及军备储备政策；

（五）与其他部长进行有效沟通与合作（与经济官员合作完成资源调配与军工建设；与军事负责人合作制定部队编制与装备更新计划；与外交官员协调军备进出口与军事援助；与情报官员配合评估敌方军力与装备威胁）。




后勤运输
“给我50架DC-3，我不在乎日本人是否占领滇缅公路。”——中国战区统帅部，1942年
海外领地的产出和国际贸易的货物需要通过运输才能到达本土。运输分为陆路和海路两种。

陆路运输：
同一大陆内的地块默认直连，资源全额到达。不同大陆之间可通过关键通道连接（见下表），通道须由己方或盟友控制，否则断开，改走海路。
关键通道	连接	控制条件
土耳其海峡	欧洲⇄亚洲	控制伊斯坦布尔地块
苏伊士运河	亚洲⇄非洲	控制苏伊士地块
乌拉尔走廊	欧洲⇄亚洲（经俄罗斯）	控制乌拉尔地块
中美洲陆桥	北美⇄南美	默认直连

海路运输：
无法陆路连接的节点之间必须走海路。海路运输受途经海域的航线安全系数影响（0~1，和平时期默认1.0，由海军力量对比决定）。
实际到达量 = 发出量 × 途经各海域安全系数之平均值

对海外领地的影响：
非核心领土产出先按占领法案折算（50%），再乘以航线安全系数（陆路可达则不乘）。
（海域划分、航线表、安全系数计算方式见附录）










军备生产
“德国新的豹式和虎式坦克可以被使用到他们自己抛锚为止，不要尝试修复。它们的引擎传动和悬挂都很烂。”——红军军械部
招募军队需要军备。每生产一定单位的军备需要消耗军工ic和一定资源，本回合交付。资源不足会导致建造失败，返还所有产能和资源。

1939 步兵军	1100	80 炮，80 钢，8 钨

科研速度与超前惩罚：

每个国家每回合只能主动研发1个科技。研发一个科技的标准支出是1000ic，科研速度会先相加再裁定效果：若相加结果为正（以＋10%为例）：则会获得1000*10%=100ic的盈余，该盈余会被存储进“科研槽”。当科研槽中存储了超过1000ic时，玩家可以选择一个不受超前惩罚的科技完成研究；若相加结果为负（以-10%为例）：则玩家需要1000*（1+10%）=1100ic才能研发一个科技。

若玩家决定超前研究科技（例，在1940年研发1942年科技），会受到超前惩罚，具体为：每超前一级研究科技，则所需ic数目翻5倍。例如，在开局（1938年）时研究1939年科技，需要5000ic；研究1942年科技则需25000ic，研究1945年科技需要125000ic。另外，在未完成前级科技的研发之前，不能研发之后的科技。


超级科技

当有玩家研发出军事科技的第4级时，会获得强力武器并触发事件；当有玩家研发出工业/资源/电子学科技的第4级时，如果继续投入对这些科技的研发（超前惩罚照吃），会获得相对应的超级科技，得到某些强力buff或武器。
